## 📖 Описание

Этот проект предоставляет удобный способ конвертировать файлы различных форматов через **контекстное меню Windows**. После установки, пользователь может кликнуть правой кнопкой мыши по любому файлу и выбрать **"Конвертировать файл"**, чтобы открыть графический интерфейс с доступными действиями.

---

## 🧩 Компоненты проекта

| Компонент          | Назначение                                                                                    |
|--------------------|-----------------------------------------------------------------------------------------------|
| **`run.py`**       | Главный исполняемый файл, запускающий GUI.                                                    |
| **`setup.py`**     | Регистрирует пункт в контекстном меню Windows.                                                |
| **`uninstall.py`** | Удаляет пункт из контекстного меню.                                                           |
| **`config.json`**  | Хранит список доступных действий и их привязку к модулям.                                     |
| **`audio_settings.json`** | Настройки пресетов для аудиоконвертации.                                               |
| **`modules/actions/`** | Папка с модулями, содержащими реализацию действий.                                        |
| **`ffmpeg`**       | Внешний инструмент для работы с аудио/видео.                                                  |

## 🛠 Установка и настройка

### 1. Установка зависимостей

- Убедитесь, что `ffmpeg` установлен и добавлен в `PATH`:

 bash
 ffmpeg -version

 bash
 pip install -r requirements.txt

### 2. Установка в контекстное меню

- Запустите от имени администратора:

 bash
 python setup.py

### 3. Удаление из контекстного меню

- Запустите от имени администратора:

 bash
 python uninstall.py

## 🚀 Использование

   1. Кликните правой кнопкой мыши по файлу (изображение, PDF, аудио, видео).
   2. Выберите "Конвертировать файл".
   3. В появившемся окне выберите нужное действие.
   4. Нажмите "Выполнить".

## 🧩 Расширение функционала

### Добавление новых действий
   1. Создайте файл в папке modules/actions/, например my_converter.py.
   2. Определите класс вида {action_name}Action, например ResizeImageAction.
   3. Реализуйте метод, например resize_image.
   4. Зарегистрируйте его в config.json:
 json
   {
    "display": "Название действия",
    "module": "actions.my_converter",
    "function": "resize_image"
   }
